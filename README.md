# MedTaurus

Academic website developed for the Medicine program at **UNIFAJ (Universidade de Jaguariúna)**.

## About

MedTaurus is a web project focused on creating a modern and accessible digital platform for the Medicine program.

The website is currently under development and will provide relevant information and resources for students and members of the academic community.

## Technologies

- HTML5
- CSS3
- JavaScript

## Status

**In Development**

The project is continuously evolving, with new features and improvements being implemented.

## Purpose

The project aims to combine academic needs with practical web development, serving as an opportunity to apply and improve front-end development skills.
